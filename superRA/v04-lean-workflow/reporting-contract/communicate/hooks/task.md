## Objective

Enforce Communicate around main-agent Markdown edits through the existing hook infrastructure.

- **Hard-gate Markdown mutation before it happens.** On main-agent `Edit`, `Write`, harness-equivalent patch calls, and supported Bash mutations that create or modify a `.md` file, inspect transcript evidence for the `superRA:communicate` load. Missing evidence denies the tool call with the exact load action and invites a retry. Non-Markdown operations and retries after the evidence appears pass silently; an unreadable target, command, or transcript follows the existing fail-open hook convention.
- **Prompt after every Markdown edit under the task tree.** Emit non-blocking context: if the edited text is user-facing, confirm it follows `superRA:communicate`; otherwise continue. Apply this to `Edit`, `Write`, and harness-equivalent patch calls without status or before-state tracking.
- Preserve Claude, Codex, and Cursor registry compatibility. Update the source hook, generated shim source, hook registries, deterministic tests, and live harness probes through their owning generators rather than hand-editing generated files.
- Verify the hard gate across Markdown/non-Markdown targets, missing/present load evidence, retry, supported Bash forms, and fail-open cases. Verify the reminder covers Markdown edits inside the task tree, stays silent outside it and for non-Markdown edits, and preserves other post-edit feedback.

## Details

- Pre-tool precedent: [`ensure-companion`](../../../../../hooks/ensure-companion) (formerly `ensure-using-superra`) reads transcript skill events and emits a deny payload. Reuse the mechanism; do not fold Markdown policy into the phase-skill guard.
- Post-tool owner: [`task_hook.py`](../../../../../skills/task-tree/scripts/task_hook.py) already reconciles edited `task.md` files and emits non-blocking feedback. Extend its source; [`hooks/task-hook`](../../../../../hooks/task-hook) is generated by `wrapper_resolver.py`.
- Interpret “task files, reporting, or communication skill” in the final architecture through the owning context: all Markdown needs `superRA:communicate`, with domain skills still loaded when their existing triggers apply (the additional task-read evidence requirement was dropped in `9f63e881` — see Results). Do not retain `report-in-markdown` as a legacy bypass after it is retired.

## Results

The hook layer now enforces Communicate before main-thread Markdown writes and reminds after every Markdown edit under a task tree.

- Markdown mutations are gated across Claude `Edit`/`Write`, Codex `apply_patch`, and supported Bash forms ([communicate_gate.py](../../../../../hooks/communicate_gate.py)).
  - Every Markdown target requires `superRA:communicate`. The original task-read requirement for task-owned Markdown was dropped in `9f63e881` — it false-positived on Read-tool views and on planners editing trees they had just created. Read-before-write stays instruction-level (`using-superra` §Task Interface, role-skill step 2) and is still asserted by the live probes in `tests/harness-instruction-following/transcript_assertions.py`.
  - Retries pass after the load evidence appears. Missing targets, unsupported commands, unreadable transcripts, and subagent calls fail open.
- Post-edit feedback is path-based and non-blocking ([task_hook.py](../../../../../skills/task-tree/scripts/task_hook.py)).
  - Every `Edit`, `Write`, or `apply_patch` touching Markdown under `superRA/` or a supported legacy task root emits one reminder to apply Communicate when the text is user-facing.
  - Markdown outside the task tree and non-Markdown files stay silent. Multiple Markdown paths in one patch are deduplicated into one reminder.
  - Status-transition parsing and pre/post snapshot state were removed.
- Hook packaging remains aligned across Claude, Codex, and Cursor.
  - The task-hook shim remains generated from [wrapper_resolver.py](../../../../../skills/task-tree/scripts/wrapper_resolver.py); no wrapper change was required.
  - Deterministic verification passed 26 gate cases and 35 focused task-hook cases ([gate tests](../../../../../tests/hooks/test-ensure-communicate.sh)).
  - After refreshing the local plugin cache, an in-session Codex `apply_patch` probe emitted the Communicate reminder after editing this Results section.
  - The paid/authenticated live probes were syntax-checked but not executed.
