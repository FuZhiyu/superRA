## Objective

Enforce two main-agent writing checks through the existing hook infrastructure without blocking task-status completion.

- **Hard-gate Markdown mutation before it happens.** On main-agent `Edit`, `Write`, harness-equivalent patch calls, and supported Bash mutations that create or modify a `.md` file, inspect transcript evidence for the target's required task context and `superRA:communicate` load. Missing evidence denies the tool call with the exact load/read action and invites a retry. Non-Markdown operations and retries after the evidence appears pass silently; an unreadable target, command, or transcript follows the existing fail-open hook convention.
- **Prompt after a direct transition to `implemented`.** Never deny or revert the status change. Emit non-blocking context asking the agent to confirm that it loaded Communicate and reviewed the task's human-facing writing; if either is missing, load the skill and run a final writing pass before the next workflow action.
  - Fire once for the edit that directly changes the leaf task's status to `implemented`.
  - Ignore later edits to an already-implemented task, ancestor rollups, and status propagation performed by the hook itself.
  - The final pass checks the Communicate core plus `structures`, `rewrite`, or `friction-audit` when their load conditions match; fix the task text in place without changing the accepted status.
- Preserve Claude, Codex, and Cursor registry compatibility. Update the source hook, generated shim source, hook registries, deterministic tests, and live harness probes through their owning generators rather than hand-editing generated files.
- Verify the hard gate across Markdown/non-Markdown targets, missing/present load evidence, retry, supported Bash forms, and fail-open cases. Verify the reminder is non-blocking, transition-specific, non-repeating, and carries the missing-load plus final-review actions on every supported status-edit path.

## Planner Guidance

- Pre-tool precedent: [`ensure-using-superra`](../../../../../hooks/ensure-using-superra) reads transcript skill events and emits a deny payload. Reuse the mechanism; do not fold Markdown policy into the phase-skill guard.
- Post-tool owner: [`task_hook.py`](../../../../../skills/task-tree/scripts/task_hook.py) already reconciles edited `task.md` files and emits non-blocking feedback. Extend its source; [`hooks/task-hook`](../../../../../hooks/task-hook) is generated by `wrapper_resolver.py`.
- Interpret “task files, reporting, or communication skill” in the final architecture through the owning context: task Markdown needs its task-read context and `superRA:communicate`; other Markdown needs `superRA:communicate`, with domain skills still loaded when their existing triggers apply. Do not retain `report-in-markdown` as a legacy bypass after it is retired.

## Results

The hook layer now enforces Communicate before main-thread Markdown writes and prompts once after a leaf task moves directly to `implemented`.

- Markdown mutations are gated across Claude `Edit`/`Write`, Codex `apply_patch`, and supported Bash forms ([communicate_gate.py](../../../../../hooks/communicate_gate.py)).
  - Every Markdown target requires `superRA:communicate`; task-owned Markdown also requires its exact `superra task read` context.
  - Retries pass after both evidence fields appear. Missing targets, unsupported commands, unreadable transcripts, and subagent calls fail open.
- Implemented-status feedback is non-blocking, transition-specific, and one-shot ([task_hook.py](../../../../../skills/task-tree/scripts/task_hook.py)).
  - A pre/post snapshot covers `Write` and Bash paths that carry no before-state; `Edit` and `apply_patch` retain diff-based fallback coverage.
  - The reminder excludes later edits and ancestor rollups, preserves `status: implemented`, and names the Communicate core and conditional final-pass references.
- Hook packaging remains aligned across Claude, Codex, and Cursor.
  - The task-hook shim was regenerated from [wrapper_resolver.py](../../../../../skills/task-tree/scripts/wrapper_resolver.py); both authenticated live probes now load Communicate and task context before their Markdown edit.
  - Deterministic verification passed 27 gate cases, 38 focused task-hook/shim cases, the existing hook suites, and the cross-harness compatibility check ([gate tests](../../../../../tests/hooks/test-ensure-communicate.sh)).
  - The paid/authenticated live probes were syntax-checked but not executed.
