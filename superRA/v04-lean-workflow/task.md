## Objective

Redesign the superRA workflow for frontier-model economics: retire the dedicated role agents in favor of role skills, make independent review triggered rather than mandatory, make interactive the default execution mode, and enforce a concise-writing and reporting contract that ends duplicated, over-long task files and conversation re-narration.

### Context

Design contract for every subtask:

- Roles become skills: dispatched general-purpose agents load role skills; the `agents/` prototype specs and their Codex generation plumbing are retired.
- Review is triggered, not scheduled: implementer self-check always; independent review only on user request, a planner high-stakes mark, or an implementer concern/uncertainty return; one thorough pass at the INTEGRATE boundary remains the safety net.
- Interactive is the default execution mode; subagent mode runs on user request or agent recommendation — recommend with a one-line rationale, never silently switch.
- Scope discipline: deliver what was asked at the scope intended unless the task is explicitly open-ended.
- Task files are the primary documents and hold only what must be preserved; conversation carries deltas and pointers; possibly-relevant extras go to conversation first and enter the task file only if the researcher wants them.
- Teach principles with an example or two, in the register they prescribe, placed where agents already are when the behavior applies — not enumerated rule catalogs.
- Checklist recalibration collapses severities to blocking/advisory and deletes verification scaffolding; no "what not to flag" exclusion lists.
- Out of scope for v0.4: rewriting the showcase/docs-site exemplars and hygiene cleanup of this repo's existing task files.

Evidence base: [review-prompting research](attachments/research-review-prompting.md), [concise-writing research](attachments/research-concise-writing.md), [review-architecture map](attachments/map-review-architecture.md), [writing-surfaces map](attachments/map-writing-surfaces.md).

### Constraints

- This repo's `CLAUDE.md` contributor gates (DRY/Necessity line tests) apply to every subtask; the task that invalidates any `CLAUDE.md`, `README.md`, or `docs/site` statement — ownership rows, Agent Load Surface entries, and design-principle prose alike — updates it in the same change (inventory: [map-review-architecture.md](attachments/map-review-architecture.md) §6 tier 5).
- `.codex/agents/*.toml` are generated by `skills/codex-superra-setup/scripts/sync_codex_agents.py`; retire or regenerate through the generator, never hand-edit.
- The harness-instruction-following test suite (`tests/harness-instruction-following/`) cites role-spec files and line ranges; keep it green in whichever task moves what it cites.
