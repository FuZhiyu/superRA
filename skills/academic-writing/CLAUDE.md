# Academic Writing Contributor Notes

## Mode and workflow boundaries

[SKILL.md](SKILL.md) routes four modes: Proofread, Polish, Draft, and Review. It owns the shared reader test, the author's decisions, the edit bars, the diff audit, and where displaced material goes. Keep workflow status and dispatch in the superRA workflow skills. The writing-owned review-only task-tree entry point is [long-form-review.md](references/long-form-review.md) with [planning.md](references/planning.md).

## Extension rules

- **Add only constraints a strong general editor would otherwise get wrong** on shared academic drafts; baseline competence needs no rule.
- **Add a rule to the reference that owns its concern;** point to it from elsewhere.
- **Add a knowledge file only for a load condition** no existing reference covers.
- **Add a mode only when** Proofread, Polish, Draft, and Review cannot describe the request and the new mode needs its own bar and load set.
- **Keep math notation with `theory-modeling`;** writing conventions cover prose typography, terminology, citations, numbers, cross-references, voice, tense, and abbreviations.
