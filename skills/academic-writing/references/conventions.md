# Manuscript Writing Conventions

**Record the paper's conventions beside the manuscript.** Use the manuscript folder's existing `CLAUDE.md` or `AGENTS.md`. If neither exists, create the instruction file used by the project's harness on the first Draft or long-form Review. Inventory any missing conventions on those passes using the draft and the relevant consistency and style references. Keep the record current as the author settles choices.

**Record only choices a fresh agent would otherwise make differently.**

| Convention | What to record | Acid test |
|---|---|---|
| Terminology | Canonical term and first use for each key concept with plausible synonyms. | Would a fresh agent pick a synonym? |
| Abbreviations | Spell-out, short form, and first use. | Would it choose another short form or spell it out again? |
| Citations | Narrative vs. parenthetical syntax, “et al.” threshold, multi-citation separators, and usage of e.g., i.e., and cf. | Would it choose different citation wording or punctuation? |
| Numerical formatting | Rounding precision, standard-error or confidence-interval delimiters, units, and percent vs. percentage points. | Would it choose a different precision, delimiter, or unit? |
| Cross-references | Reference phrasing and label prefixes. | Would it write “Sec. 3” where the paper uses “Section 3”? |
| Voice and tense | First person and passive voice, tense for procedures and results. | Would it switch voice or tense across comparable passages? |
| Prose typography | Type and accents around notation in prose, quotation marks, and dash style. | Would it choose different typography for the same prose use? |

**Follow the owning conventions.** [Theory modeling](../../theory-modeling/SKILL.md) owns symbol meanings and equation numbering. The venue or template governs section and caption capitalization and page layout.
