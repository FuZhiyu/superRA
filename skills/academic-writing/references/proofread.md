# Proofread Mode

- **Use the [Proofread bar](../SKILL.md#mode-routing).** Check only the requested text and its sources. Use [Fix tiers](review.md#fix-tiers) for apply decisions.
- **Propagate changed results in the simplest correct words.** Match exact quantities to their source at the stated precision. Keep an approximation while it holds at the precision the prose conveys. Correct it when the new value falls outside that range. Use [Substance is the author's](../SKILL.md#substance-is-the-authors) when the message changes.
- **List issues noticed below the bar in the return.** Leave the wording in place.
