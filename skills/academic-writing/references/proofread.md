# Proofread Mode

- **Use the [Proofread bar](../SKILL.md#mode-routing).** Check only the requested text and its sources. Use [Fix tiers](review.md#fix-tiers) for apply decisions.
- **Propagate changed results in the simplest correct words.** Match exact quantities to their source at the stated precision. Keep an approximate number ("about", "approximately", "roughly") while the new value is within about one rounding step of it and the message is unchanged. Correct it once it drifts further. Use [Substance is the author's](../SKILL.md#substance-is-the-authors) when the message changes.
- **List issues noticed below the bar in the return.** Leave the wording in place.
